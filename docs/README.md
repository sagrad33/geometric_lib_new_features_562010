# **Geometric_lib**

## **Примененные математические формулы**

### Площадь
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²
- Triangle: S = (a*h)/2

### Периметр
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
- Triangle: P = a + b + c


## **Описание функций**

### **1. Круг (circle.py)**

*   **`area(r)`** : Принимает радиус r, возвращает площадь круга.
    
    **Параметры:**
    * `r`: радиус круга.
    
    **Возвращаемое значение:**
    * `math.pi * r * r`: площадь круга.

    **Пример вызова:**
    ```python
    import circle
    print(circle.area(3))
    
    >>> 28.274333882308138
    ```

*   **`perimeter(r)`** : Принимает радиус r, возвращает длину окружности (периметр).
    
    **Параметры:**
    * `r`: радиус круга.
    
    **Возвращаемое значение:**
    * `2 * math.pi * r`: длина окружности.

    **Пример вызова:**
    ```python
    import circle
    print(circle.perimeter(3))
    
    >>> 18.84955592153876
    ```

### **2. Прямоугольник (rectangle.py)**

*   **`area(a, b)`** : Принимает стороны прямоугольника a и b, возвращает его площадь.
    
    **Параметры:**
    * `a`: первая сторона прямоугольника.
    * `b`: вторая сторона прямоугольника.
    
    **Возвращаемое значение:**
    * `a * b`: площадь прямоугольника.

    **Пример вызова:**
    ```python
    import rectangle
    print(rectangle.area(4, 6))
    
    >>> 24
    ```
 
*   **`perimeter(a, b)`** : Принимает стороны прямоугольника a и b, возвращает его периметр.
    
    **Параметры:**
    * `a`: первая сторона прямоугольника.
    * `b`: вторая сторона прямоугольника.
    
    **Возвращаемое значение:**
    * `2 * (a + b)`: периметр прямоугольника.

    **Пример вызова:**
    ```python
    import rectangle
    print(rectangle.perimeter(4, 6))
    
    >>> 20
    ```

### **3. Квадрат (square.py)**

*   **`area(a)`** : Принимает сторону квадрата a, возвращает площадь квадрата.
    
    **Параметры:**
    * `a`: сторона квадрата.
    
    **Возвращаемое значение:**
    * `a * a`: площадь квадрата.

    **Пример вызова:**
    ```python
    import square
    print(square.area(5))
    
    >>> 25
    ```

*   **`perimeter(a)`** : Принимает сторону квадрата a, возвращает периметр квадрата.
    
    **Параметры:**
    * `a`: сторона квадрата.
    
    **Возвращаемое значение:**
    * `4 * a`: периметр квадрата.

    **Пример вызова:**
    ```python
    import square
    print(square.perimeter(5))
    
    >>> 20
    ```

### **4. Треугольник (triangle.py)**

*   **`area(a, h)`** : Принимает сторону a и высоту h, возвращает площадь треугольника.
    
    **Параметры:**
    * `a`: основание треугольника.
    * `h`: высота треугольника.
    
    **Возвращаемое значение:**
    * `a * h / 2`: площадь треугольника.

    **Пример вызова:**
    ```python
    import triangle
    print(triangle.area(4, 5))
    
    >>> 10.0
    ```

*   **`perimeter(a, b, c)`** : Принимает три стороны a, b, c, возвращает периметр треугольника.
    
    **Параметры:**
    * `a`: первая сторона треугольника.
    * `b`: вторая сторона треугольника.
    * `c`: третья сторона треугольника.
    
    **Возвращаемое значение:**
    * `a + b + c`: периметр треугольника.

    **Пример вызова:**
    ```python
    import triangle
    print(triangle.perimeter(3, 4, 5))
    
    >>> 12
    ```
